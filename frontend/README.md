# OpenTrivia Frontend

The frontend is built with Angular.

## Prerequisites

- Node.js and npm

## Running the Application

1. Open a terminal in the project's root directory.
2. Ensure that port `4020` is not already in use.
3. Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

4. Install the dependencies if you haven't already:

   ```
   npm install
   ```

5. Start the application:

   ```
   npm start
   ```

The frontend runs on port 4020
